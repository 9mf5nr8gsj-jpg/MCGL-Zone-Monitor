MCGL Zone Monitor — PWA, тестовая сборка.

ЗАГРУЗКА НА GITHUB:
1. Распакуй архив в приложении «Файлы».
2. В репозитории MCGL-Zone-Monitor нажми Add file -> Upload files.
3. Загрузи ВСЁ содержимое этой папки: index.html, style.css, app.js, manifest.json, service-worker.js и папку icons.
4. Commit changes. Подожди публикации GitHub Pages.
5. Открой адрес GitHub Pages в Safari -> Поделиться -> На экран Домой.

ВАЖНО:
- База IndexedDB хранится локально в Safari на этом устройстве. Регулярно экспортируй CSV/JSON.
- Это ранний интерфейс и диагностическая HTTP-проверка. HTTP 200/404 не превращаются автоматически в статусы зоны: нужно подтвердить HTML-сигнатуры.
- Запросы к MCGL из GitHub Pages могут блокироваться CORS. Если это произойдёт, потребуется серверный посредник; GitHub Pages не выполняет серверный код.
- iOS может приостанавливать PWA в фоне. Для постоянного фонового мониторинга понадобится сервер.
- Не начинай с 150 потоков: проверь доступность на 5–10.
